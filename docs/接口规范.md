# 薇斯纳桌宠 · 接口规范

这份文档定下三件事：扩展能用哪些接口，她"在忙什么"怎么算，什么情况下谁会让路。
加新互动之前先看这里；规则变了先改代码里的表，再改这份文档。

## 0. 分层

| 层 | 位置 | 怎么接 | 能碰内部字段吗 |
|---|---|---|---|
| 本体 | `main.py` `panels.py` `effects.py` … | — | 能 |
| 核心效果模块 | `food_fx.py` `companion.py` | 本体直接调用 | 能(和本体一起改) |
| 互动插件 | `dlc/interactions/*.py` | 同进程，钩子 + 第 2 节的公开接口 | **不能** |
| 外部 DLC | 独立进程(如 `dlc/chat`) | 本机管道，见 `live_link.py`：读快照、收事件、`say` | 不能(也碰不到) |

插件和外部 DLC 都**改不了**好感/饱腹之外的存档结构；外部 DLC 连好感/饱腹也改不了。

## 1. 插件怎么写

- 文件放 `dlc/interactions/<名字>.py`，`_` 开头的不加载。模块提供 `create(pet, log_fn)`，返回插件对象；返回 `None` 表示这次不加载(比如缺素材)。
- 插件可设 `priority`(默认 0)，大的先被问；同级按文件名顺序。
- 钩子抛异常：记一条 `error.log`，**这个插件被停用**，其他插件和本体照常。`menu_items` / `settings_rows` 出错只跳过那一项。
- 检查有没有越界：`python tools/check_plugins.py`(碰了 `p._xxx` 就报)。

### 钩子

| 钩子 | 什么时候调 | 返回值 |
|---|---|---|
| `on_event(name, data)` | 她身上发生的每个事件(第 5 节) | 不管；只通知 |
| `busy() -> str \| None` | 每次有人查 `activities()` | 非空 = 插件正在进行的活动名，自动行为会让路(第 3、4 节)。**不要在里面调 `pet.activities()`** |
| `step(t)` | 每帧(约 60 次/秒) | 不管 |
| `paint(key, pm, t) -> (pm, dx)` | 画立绘前 | 换图 / 水平抖动；`None` = 不改 |
| `on_pet() -> bool` | 摸头时，原版效果之前 | `True` = 插件接管 |
| `on_mouse_press(event) -> bool` | 任意键按下 | `True` = 吃掉这次按下 |
| `on_wheel(event) -> bool` | 滚轮转圈前 | `True` = 吃掉(不转、不攒晕度) |
| `on_context_menu(event) -> bool` | 右键菜单弹出前 | `True` = 不弹 |
| `on_spin_queasy(now) -> bool` | 转太多、即将"晕完生气"时 | `True` = 插件接管收尾(记得调 `take_over_spin`) |
| `on_say(text, src)` | 她冒台词气泡时 | 不管 |
| `menu_items() -> [(emoji, label, fn)]` | 建菜单时 | 注册到右键卡片和托盘「互动」 |
| `settings_rows() -> [dict]` | 建设置页时 | `{key, emoji, title, desc, control, sync?}` |

### 约定

- 台词走 `pet.say(..., src="<插件名>")`；语音插件只给 `src="pet"` 的台词配音。
- 自己的计数用 `pet.stats.inc("<名字>")`，重启后保留；更复杂的数据存 `stats.data_dir() / "<插件名>.json"`。
- 自己发的事件起个不和原版重名的名字，用 `pet.emit_event(name, **字段)`；它会同时推给其他插件和外部 DLC。
- 要"她闲着才做"的事，先查 `pet.activities()`，把会冲突的活动名写成一个集合常量(参考 `water.py` 的 `BUSY`)。

## 2. 桌宠公开接口(`pet`)

下划线开头的属性和方法**都不在**这里，随时可能改名或改含义。

### 只读

| 名字 | 说明 |
|---|---|
| `state` | 当前表情：`idle happy angry sleep surprised wave stretch yawn cheer dizzy look look_left eat content shy focus love` |
| `dragging` / `landed` | 正被拖着 / 不在跳跃半空 |
| `fling` / `walk` / `edge` / `food_fx` / `link_busy` | 非空/真 = 在飞或滑 / 在走 / 贴在哪条边(`left right top`) / 有吃后效果 / Grok 联动在忙 |
| `sulking()` / `focusing()` / `sneaking()` / `isVisible()` | 闹别扭 / 专注计时中 / 偷吃中 / 看得见 |
| `activities()` / `can_auto(what)` | 见第 3、4 节 |
| `char_w` `char_h` `pad_x` | 立绘尺寸、左右留白(像素) |
| `head_point()` `mouth_point()` `foot_point()` `anchor_point()` | 屏幕坐标，放粒子/气泡用 |
| `screen_rect()` | 她所在屏幕的可用区域(扣掉任务栏) |
| `stats` | `hunger` `affection` `level()` `food_count(key)` `seen(key)` |
| `cfg` | 设置(`cfg["mute"]` `cfg["sfx"]` `cfg["walk"]` …)，只读 |
| `danika.active()` / `butterfly.active()` | 达妮卡在 / 蝴蝶在 |

### 动作

| 名字 | 说明 |
|---|---|
| `set_state(state, duration=None, why=None)` | 换表情，`duration` 秒后回 idle(闹别扭时回 angry)；`why` = 从睡着换走时记的醒来原因 |
| `say(text, force=False, duration=None, tone=None, src="pet")` | 冒气泡；`force` 无视勿扰；`tone`: `normal happy alert info cool` |
| `quip(pool, urgent=False, gap=1.1, **say参数)` / `pick_line(pool)` | 节流地说一句 / 不连续重复地挑一句 |
| `burst(kind, n=1, at=None, bias=None, text="", pm=None)` | 粒子：`heart sparkle star confetti anger sweat drop steam puff dust note quest excl orbit ring z crumb gust emoji(text=)` |
| `kick(v)` / `do_jump(big=False)` / `celebrate()` | 果冻弹一下 / 跳 / 欢呼+彩纸 |
| `sfx.play(name)` | `pop boing chime sparkle munch level huh hmph tick whoosh bonk` |
| `gain(n, kind=None, quiet=False)` | 加减好感；`kind` 计入每日上限 |
| `stats.inc(key, n=1)` / `stats.add_hunger(delta)` | 计数(重启保留) / 加减饱腹(夹在 0–100) |
| `emit_event(name, **data)` | 发事件给插件和外部 DLC |
| `note_interaction()` / `stop_walk()` / `wake_up(why)` | 算一次互动(重置犯困) / 停下不走 / 惊醒 |
| `clear_sulk()` | 悄悄结束闹别扭(无台词、无 +1)；要原版的消气演出别用它 |
| `force_struggle(stage, since=None)` | 拖着时按挣扎阶段 1–4 抖、不说台词；每帧传同一个 `since` 才连续；`0` = 重新计时 |
| `take_over_spin(dizzy_sec, refuse_sec, now=None)` | 接管"转太多"的收尾：晕多久、多久内拦住下一次转 |
| `clear_dizzy()` | 马上不算晕 |
| `tilt` `spin_rem` `spin_angle` | 动画字段，可写(比如把 `spin_rem` 清零 = 停止转圈) |

## 3. 活动(`activities()`)

`pet.activities()` 返回一个集合，表示她此刻在做的事。定义在 `main.py` 的 `ACTIVITIES` / `activities()`。

| 名字 | 含义 |
|---|---|
| `hidden` | 隐藏着 |
| `sleep` | 睡着 |
| `edge` | 贴边探头 |
| `drag` | 被拖着 |
| `fling` | 甩出去/被丢，还在飞或滑 |
| `throw` | 被丢：从飞出去到落地抱怨完 |
| `walk` | 散步/走过来 |
| `chase` | 追蝴蝶 |
| `sneak` | 偷吃 |
| `food_fx` | 食物包吃后效果 |
| `sulk` | 闹别扭 |
| `spin` | 滚轮转圈中，或转过头、等着发作 |
| `dizzy` | 晕着(表情是 dizzy，或晕的计时还没到) |
| `danika` | 达妮卡来访 |
| `butterfly` | 蝴蝶在场 |
| `panel` | 开着面板(小屋/运势/猜拳等) |
| `focus` | 专注计时中(暂停不算) |
| `link` | Grok 联动工作中 |
| `plugin` | 有插件的 `busy()` 非空；同时那个名字也在集合里(现有：`vomit` `water` `water_force` `rage`) |

## 4. 互动矩阵：自动行为什么时候让路

她自己发起的事，开始前查 `main.py` 的 `AUTO` 表：表情不在白名单，或和下表打 ● 的活动有交集，就不做。
**改规则只改 `AUTO`**，然后 `python tools/print_matrix.py` 重新生成下表贴回来。

| 自动行为 | 只在这些表情 | hidden | sleep | edge | drag | fling | throw | walk | chase | sneak | food_fx | sulk | spin | dizzy | danika | butterfly | panel | focus | link | plugin |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 空闲小动作 `idle_action` | idle | ● |  |  | ● | ● |  | ● |  |  | ● |  |  |  |  |  |  |  |  | ● |
| 达妮卡自己来 `danika_auto` | 不限 |  |  | ● |  |  |  |  |  |  |  | ● |  |  | ● | ● | ● | ● | ● |  |
| 叫达妮卡(手动也查) `danika` | 不限 |  | ● | ● | ● | ● |  | ● |  |  |  | ● |  |  |  |  |  |  | ● |  |
| 随机冒一句 `random_bubble` | idle、happy | ● |  |  | ● |  |  |  |  |  | ● |  |  |  | ● |  |  | ● | ● | ● |
| 偷吃 `sneak` | idle |  |  | ● | ● | ● |  | ● |  |  |  | ● |  |  | ● | ● |  | ● | ● | ● |
| 蝴蝶自己飞来 `auto_butterfly` | 不限 | ● | ● |  | ● |  |  |  |  |  | ● |  |  |  |  | ● |  | ● |  | ● |
| 去追蝴蝶 `chase` | 不限 | ● | ● | ● | ● | ● |  |  |  |  | ● | ● |  | ● | ● |  | ● | ● | ● | ● |
| 没人理就睡着 `fall_asleep` | idle |  |  |  | ● | ● |  | ● |  |  |  |  |  |  |  |  |  |  |  |  |
| 喝水/久坐/整点/饿了提醒 `reminder` | 不限 |  |  |  |  |  |  |  |  |  |  | ● |  |  |  |  |  | ● |  |  |
| DLC 的 say `live_say` | 不限 |  | ● |  | ● | ● | ● |  |  |  | ● |  | ● | ● | ● |  |  |  |  | ● |

表外的规则(还写在代码里)：

- `idle_action` 抽中达妮卡时，还要过 `danika_auto`，并且离上次来访 20–35 分钟以上。
- `fall_asleep`：吃后效果期间、专注期间她一直算"刚被互动过"，不会犯困。
- `reminder`：她睡着或隐藏时提醒不响，久坐计时清零；"饿了"还要求表情是 idle。
- `chase` 另外要求设置里「散步」开着；`auto_butterfly` 另外要求「蝴蝶」开着。

### 矩阵里看出来的疑点(行为没改，等确认)

1. **提醒会抢达妮卡的戏。** `say()` 的注释说达妮卡对话期间只放她的对白，但喝水/久坐/整点提醒用的是 `force=True`，`reminder` 也没被 `danika` 拦，所以会插进对话里。改法：`reminder` 加上 `danika`。
2. **提醒会插进拖拽、究极生气、转吐。** `reminder` 只被 `focus` `sulk` 拦，提醒时会把表情换成挥手/伸懒腰。改法：再加 `drag` `fling` `plugin`。
3. **达妮卡和蝴蝶互相让路不对称。** 蝴蝶在时达妮卡不来，但达妮卡在时蝴蝶照样飞来。改法：`auto_butterfly` 加上 `danika`。
4. **闹别扭时蝴蝶照样飞来**(只是她不追)。可能是想要的效果，也可能不是。

## 5. 事件

插件经 `on_event(name, data)` 收到全部事件；外部 DLC 要先 `subscribe`(见 `live_link.py`)。

| 事件 | 字段 |
|---|---|
| `click` / `double_click` | — |
| `pet` | `sleeping` `sulking` |
| `drag_start` / `drag_end` | `was_sleep` / `held` `thrown` |
| `throw` / `bonk` / `throw_land` | `speed` `hard` `level` / `impact` / `level` `wall` `bonks` |
| `spin_start` / `spin_end` / `dizzy` | — / `meter` / `why`: `spin` `wall` |
| `feed` | `key` `name` `tier` `trait` `reaction`(`fav like ok dislike weird refuse full sulk_worse`) `first` |
| `sleep` / `wake` | — / `why`: `pet drag spin click feed butterfly water other` |
| `state` | `from` `to`(每次换表情都有，很频繁) |
| `say` | `text` `src` |
| `idle_action` / `sneak_caught` | `act` / — |
| `sulk` / `makeup` / `level_up` | `again` / `how` / `name` |
| `danika_visit` / `danika_end` | `auto` / `skipped` |
| `butterfly` | `stage`: `come caught landed giveup`，`auto` |
| `food_effect_start` / `food_effect_end` | `key` `name` `effect` / 加 `why`: `done sleep hidden throw spin drag` |

| 插件发的：`watered` `comforted` `companion_bonus` `vomit` | 见各插件文件开头 |

## 6. 用户操作会打断什么

| 操作 | 效果 |
|---|---|
| 左键按下 | 跳过达妮卡对话；半空中接住(这次被丢不再抱怨)；停下散步；不再追蝴蝶 |
| 拖动 | 睡着 → 被拎醒(不满、扣好感，5 分钟冷却)；探头 → 离开墙；吃后效果结束(`hyper` `babble` `burp` `shock` 不会被拖断) |
| 单击 | 睡着 → 点醒；偷吃中 → 被抓包；闹别扭 → 轻点几下能哄好，连戳更气；连点 3 下 → 生气 |
| 双击 | 睡着 → 点醒；闹别扭 → 算戳；连点 → 生气；否则大跳 |
| 摸头(头上左右蹭) | 停下散步；睡着 → 摸醒；插件先问(`comfort` 哄、`water` 究极生气时拍开)；闹别扭 → 消气 |
| 投喂 | 停下散步；睡着 → 叫醒；闹别扭时好吃的能哄好、讨厌的更气 |
| 滚轮 | 停下散步；插件先问(究极生气时不让转)；睡着 → 转醒生气；被拖/在飞时不转；闹别扭 → 扭头 |
| 隐藏 / 睡着 / 被丢 / 转圈 | 结束吃后效果 |

## 7. 这次重构带来的行为变化

条件判断改成查表后，用 2 万组随机状态和旧写法逐条比对过，结果一致，只有下面这些有意的变化：

- 去追蝴蝶：现在"晕的计时还没到"也不追(以前只看表情是不是 dizzy)。
- 插件现在可以通过 `busy()` 报活动。`vomit` 和 `water` 报了之后，转吐、浇水、强行浇水和 45 秒究极生气期间，蝴蝶不会自己飞来，她也不去追，空闲小动作、随机冒话和偷吃都暂停，DLC 的 `say` 回 `busy`。以前究极生气时蝴蝶照样会来，她还会去追。
- `live_say` 的转圈判断从 `spin_rem > 0.5` 改成 `> 0`(差别不到一帧)。
- 插件现在收得到 `state` `sleep` `wake` 事件(以前只在接了外部 DLC 时才发)。
- 新事件：`rps` `fortune` `focus_start` `focus_end` `reminder`。
- `stats.json` 里插件用 `inc()` 记的计数(比如 `vomits`)重启后不再清零。

## 8. 还没纳入规范的

- `food_fx.py` 还直接读写 `PetWindow` 的内部字段(二十多处)。它算本体的一部分，暂时允许，以后可以按同样方式收口。
- `fall_asleep` 和 `reminder` 的副作用规则(第 4 节"表外的规则")还没进表。
