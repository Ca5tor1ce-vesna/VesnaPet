# 薇斯纳桌宠 · 接口规范

这份文档定下三件事：扩展能用哪些接口，她"在忙什么"怎么算，什么情况下谁会让路。
加新互动之前先看这里；规则变了先改代码里的表，再改这份文档。

## 0. 分层

| 层 | 位置 | 怎么接 | 能碰内部字段吗 |
|---|---|---|---|
| 本体 | `main.py` `panels.py` `effects.py` … | — | 能 |
| 核心效果模块 | `food_fx.py` `companion.py` | 本体直接调用 | 能(和本体一起改) |
| 互动插件 | `dlc/interactions/*.py` | 同进程，钩子 + 第 2 节的公开接口 | **不能** |
| 外部 DLC | 独立进程(如 `dlc/chat`) | 本机管道，见 `live_link.py`：读快照、收事件、`say` | 不能(也碰不到) |

插件和外部 DLC 都**改不了**好感/饱腹之外的存档结构；外部 DLC 连好感/饱腹也改不了。

## 1. 插件怎么写

- 文件放 `dlc/interactions/<名字>.py`，`_` 开头的不加载。模块提供 `create(pet, log_fn)`，返回插件对象；返回 `None` 表示这次不加载(比如缺素材)。
- 插件可设 `priority`(默认 0)，大的先被问；同级按文件名顺序。
- 钩子抛异常：记一条 `error.log`，**这个插件被停用**，其他插件和本体照常。`menu_items` / `settings_rows` 出错只跳过那一项。
- 检查有没有越界：`python tools/check_plugins.py`(碰了 `p._xxx` 就报)。

### 钩子

| 钩子 | 什么时候调 | 返回值 |
|---|---|---|
| `on_event(name, data)` | 她身上发生的每个事件(第 5 节) | 不管；只通知 |
| `tune(name, value, ctx) -> 新值 \| None` | 本体在决策点问(见第 2.5 节) | 新值 = 改这个参数，`None` = 不改；多个插件按 `priority` 依次传下去，本体最后校验 |
| `busy() -> str \| None` | 每次有人查 `activities()` | 非空 = 插件正在进行的活动名，自动行为会让路(第 3、4 节)。**不要在里面调 `pet.activities()`** |
| `step(t)` | 每帧(约 60 次/秒) | 不管 |
| `expr(key, state) -> str \| None` | 每帧画立绘前，`paint` 之前 | 换一张脸(第 2.6 节)：`key` 是本体选好的图，`state` 是状态；返回 `FACES` 里的名字(或任一状态名)，`None` = 不换。多个插件按 `priority` 依次传下去；只换图，状态和逻辑不变 |
| `paint(key, pm, t) -> (pm, dx)` | 画立绘前，按 `priority` 从大到小依次画(后画的盖在上面) | 换图 / 水平抖动；`None` = 不改 |
| `on_pet() -> bool` | 摸头时，原版效果之前 | `True` = 插件接管 |
| `on_click(double) -> bool` | 单击/双击时，原版的戳/跳之前(`double=True` 是双击) | `True` = 插件接管 |
| `on_mouse_press(event) -> bool` | 任意键按下 | `True` = 吃掉这次按下 |
| `on_drag_begin(pos, delta) -> bool` | 左键按住刚挪过拖动门槛、本体要开始拖她之前(`pos` = 按下的点，窗口坐标；`delta` = 已经挪了多少) | `True` = 插件接管这一下(一般在里面 `capture_mouse(self)`)，本体不拖 |
| `on_capture_press(e)` / `on_capture_move(e)` / `on_capture_release(e)` | 插件 `capture_mouse(self)` 之后，她身上的按下(双击算按下)/ 移动(按不按键都算)/ 松开 | 不管；本体这段时间不拖、不戳、不摸头、不转圈、不弹右键菜单，直到 `release_mouse()` |
| `on_feed(food) -> bool` | 投喂时最先问(`food` 是那样吃的的 dict 副本) | `True` = 插件接管这次投喂(比如假装喂)；想真的喂就调 `pet.feed(key, ask=False)` |
| `on_wheel(event) -> bool` | 滚轮转圈前 | `True` = 吃掉(不转、不攒晕度) |
| `on_context_menu(event) -> bool` | 右键菜单弹出前 | `True` = 不弹 |
| `on_spin_queasy(now) -> bool` | 转太多、即将"晕完生气"时 | `True` = 插件接管收尾(记得调 `take_over_spin`) |
| `on_eat(food, first) -> str \| None` | 她把东西吃下去时(没推开、不是整蛊食物)，原版反应之前 | 返回 `fav like ok dislike weird` = 插件接管这次的反应(表情、台词、好感自己做)，`feed` 事件按返回的档记、心情也按它算；`None` = 原版照常。饱腹、图鉴本体照常记 |
| `on_say(text, src)` | 她冒台词气泡时 | 不管 |
| `state_text() -> str \| None` | 画小屋头部时 | 插件管的短暂状态正在进行时返回一句话(如「头发还在滴水,火气倒是很旺」)，小屋头部优先显示它；平时返回 `None`。口吻和头部原来那几句一样：旁白、带点画面，不要直接报状态 |
| `status_text() -> str \| None` | 每秒刷新托盘提示时、画右键卡片时 | 一行状态：托盘提示和右键卡片的状态行里列出 |
| `menu_items() -> [(emoji, label, fn)]` | 建菜单时 | 注册到右键卡片和托盘「互动」 |
| `settings_rows() -> [dict]` | 建设置页时 | `{key, emoji, title, desc, control, sync?}` |

### 约定

- 台词走 `pet.say(..., src="<插件名>")`；语音插件只给 `src="pet"` 的台词配音。
- 自己的计数用 `pet.stats.inc("<名字>")`，重启后保留；更复杂的数据存 `stats.data_dir() / "<插件名>.json"`。
- 自己发的事件起个不和原版重名的名字，用 `pet.emit_event(name, **字段)`；它会同时推给其他插件和外部 DLC。
- 插件想让她主动开口(提要求、聊往事)，先查 `pet.can_auto("plugin_talk")` 和 `pet.bubble.isVisible()`，最好再要求安静待够几秒(参考 `wish.py`)。规则写在 `AUTO`，所有插件共用一份。
- 其他"她闲着才做"的事，查 `pet.activities()`，把会冲突的活动名写成一个集合常量(参考 `water.py` 的 `BUSY`)。

### 2.4 心情(本体)

`pet.mood` 是本体的数值，和好感、饱腹并列：**本体只负责算、存、显示(小屋状态页和右键卡片里的心情条)，不拿它改她的行为**。
要不要因为心情(或好感、饥饿)改行为，由插件通过 `tune()` 决定；不装这样的插件，心情就只是一个会变的数。

- -100..100，五档：😆 超开心(60+) / 😊 不错(25+) / 🙂 平平 / 😕 有点低落(-15 以下) / 😣 很糟(-50 以下)；换档有 6 分回差，换档推 `mood` 事件。
- 她身上的事件自动算进心情(规则在 `mood.py` 的 `event_delta`)：摸头 +4、喂最爱 +10 / 喜欢 +6、满足心愿 +8、抓到蝴蝶 +5……丢她 -6(狠丢 -10)、转吐 -12、强行浇水 -15、闹别扭 -8……
  好的互动 10 分钟内重复打折(第 n 次只算 1/n)，坏的不打折；饿着时吃到东西，开心乘 1.5。
- 不理她会回到「平常」：偏离的部分 45 分钟减半，关掉期间也算。平常心情跟好感等级走(Lv.1 +5 … Lv.6 +30)，饱腹低于 25 时往下拉(饿扁了 -20)。
- 存在 `stats.json` 的 `mood`；快照里有 `mood`(数值) 和 `mood_band`(档位)。

### 2.5 可调参数(`tune`)

本体在下面这些决策点问一句插件；插件返回新值就用新值(本体校验类型、夹在范围内，不合法就用原值)。没有插件实现 `tune` 时，行为和原版一模一样。
表在 `main.py` 的 `TUNABLE`。

| 名字 | 原值 | 类型 / 范围 | ctx | 用在哪 |
|---|---|---|---|---|
| `idle_gap` | 12–28 秒随机 | 秒，3–600 | — | 下一次空闲小动作隔多久 |
| `idle_weights` | `happy 3, look 2.2, stretch 1.2, hop 1.6, wave 1, walk 2.5, sneak 1.4` | 各项 0–50，至少一项大于 0 | — | 空闲小动作抽哪个；设置里关了散步，`walk` 插件也改不回来 |
| `bubble_gap` | 30–60 秒随机 | 秒，5–1800 | — | 下一次随机冒泡隔多久 |
| `bubble_pool` | 原版台词池(含好感、饿了的那些) | 字符串列表，不能为空 | — | 随机冒泡从哪挑 |
| `sleep_after` | 站着 180 秒 / 探头 60 秒 | 秒，15–3600 | `edge` | 多久没人理就睡着 |
| `food_refuse_p` | 不爱吃 0.45 / 奇怪的 0.6 | 0–1 | `key` `tier` `trait` | 不爱吃 / 奇怪的东西直接推开的概率(整蛊食物不走这里) |
| `food_refuse` | 上面按概率算出来的结果 | 布尔 | `key` `tier` `trait` | 最后问一句这次推不推开；喜欢的也能让她推开(比如暴雪天的冰淇淋)。整蛊食物不问 |
| `food_refuse_lines` | 这道菜自己的推开台词，没有就用原版那几句 | 字符串列表，不能为空 | `key` `tier` `trait` | 推开时说的那句 |
| `happy_lines` | 原版「开心」那几句(含「今天天气真好~」) | 字符串列表，不能为空 | — | 空闲小动作「开心」时说的那句 |
| `come_ok` | `True` | 布尔 | — | 叫她「过来~」肯不肯来；`False` 时她扭头说一句，推 `come_refused` |
| `come_refuse_lines` | 原版不肯来的台词 | 字符串列表，不能为空 | — | 不肯过来时说的那句 |
| `greet_lines` | 原版迎接台词(按离开多久、好感挑好的那组) | 字符串列表，不能为空 | `long` `level` | 你离开电脑一阵又回来，她迎接你说的那句 |
| `greet_cheer` | `True` | 布尔 | `level` | 迎接时(好感到「好友」起)要不要欢呼、蹦、冒爱心；`False` = 只挥挥手 |
| `status_line` | 原版那句(饿了 / 看蝴蝶 / 按好感) | 文字，1–20 字(超出截断) | `kind`(hungry / butterfly / level) `level` | 小屋头部「没事时」那句；有事正在发生时不问 |
| `drag_hold_rate` | `1.0` | 0–2 | `held`(真实拖了多少秒) `stage`(已经喊到第几阶段) | 拖着她时，挣扎计时走多快：0.25 = 四倍慢，1.5 = 更快；拖着时每 0.2 秒问一次 |
| `butterfly_gap` | 第一只 60–150 秒，之后 240–540 秒随机 | 秒，30–86400 | `first` | 下一只蝴蝶自己飞来要等多久 |
| `butterfly_ok` | `True` | 布尔 | — | 到点了让不让蝴蝶自己飞来；`False` = 这次不来，照常排下一次(召唤蝴蝶不受影响) |
| `hungry_remind` | 1200 秒 | 秒，0–86400；0 = 本体不提醒 | — | 本体「饿了」提醒的间隔(插件想自己管饿就设 0) |
| `sneak_done_lines` | 原版得意台词 | 字符串列表，不能为空 | — | 偷吃没被发现、吃完时说的那句 |
| `sneak_caught_lines` | 原版否认台词 | 字符串列表，不能为空 | — | 偷吃被你点到时说的那句 |

### 2.6 脸(只换图的表情)

有些表情不是新状态，只是同一个状态下换一张图：状态照旧(动作、计时、互动规则、头部那句话都不变)，画的是另一张脸。
表在 `main.py` 的 `FACES`：名字 → 它借的状态；`assets` 里没有这张图，就照常画那个状态的图(所以图可以一张张补)。

| 脸 | 状态 | 什么时候 |

| `pout` 委屈 | shy | 猜拳输给你(状态还是 angry)、追蝴蝶扑空、心愿没等到 |
| `smug` 偷笑 | content | 偷吃得手 |
| `hungry` 饿了 | idle | 饱腹低于 25 时站着发呆(`HUNGRY_FACE`)；张望、专注、散步优先 |
| `yuck` 皱脸 | angry | 辣的(喷火之后灌了口水)、苦的、蔬菜(状态是 shy)，推开不爱吃的 |
| `queasy` 难受 | dizzy | 吃了黑暗料理(转吐有插件 `vomit` 自己的立绘) |
| `sulk` 赌气 | angry | 闹别扭期间的生气 |
| `held` 被拎起 | surprised | 被拖着、被丢在半空 |

插件给的名字没有对应的图(连回退都没有)就忽略。探头时不换脸。

- `idle_action` 抽中达妮卡时，还要过 `danika_auto`，并且离上次来访 20–35 分钟以上。

### 已定的规则(2026-10-29 确认)

1. 提醒不再插进达妮卡的对话：`reminder` 加了 `danika`。
2. 提醒不再插进拖拽、甩飞、究极生气、转吐：`reminder` 加了 `drag` `fling` `plugin`。
3. 达妮卡在的时候蝴蝶照样可以飞来：保持现状，是有意的。
4. 闹别扭时蝴蝶照样飞来(她不追)：保持现状，是有意的。

## 6. 用户操作会打断什么

| 操作 | 效果 |
|---|---|
| 左键按下 | 跳过达妮卡对话；半空中接住(这次被丢不再抱怨)；停下散步；不再追蝴蝶 |
| 拖动 | 睡着 → 被拎醒(不满、扣好感，5 分钟冷却)；探头 → 离开墙；吃后效果结束(`hyper` `babble` `burp` `shock` 不会被拖断)；魂在外面 → 魂马上回来(不演醒来，原来的收尾也不做) |
| 单击 | 魂在外面 → 魂马上回来，她一激灵说一句(最先判断，插件不问)；正被哄睡 → 醒了，不高兴(其次判断，插件不问)；点那团魂本身 = 揪魂(见第 7 节)；插件先问(`water` 究极生气时另有反应，见下)；睡着 → 点醒；偷吃中 → 被抓包；闹别扭 → 轻点几下能哄好，连戳更气；连点 3 下 → 生气 |
| 双击 | 插件先问(同单击)；睡着 → 点醒；闹别扭 → 算戳；连点 → 生气；否则大跳 |
| 摸头(头上左右蹭) | 停下散步；睡着 → 摸醒；正被哄睡 → 快一步睡着(插件不问)；插件先问(`comfort` 哄、`water` 究极生气时拍开)；闹别扭 → 消气 |
| 投喂 | 先问插件 `on_feed`(`tease`：按住 Ctrl 点吃的 = 假装喂)；停下散步；睡着 → 叫醒；闹别扭时好吃的能哄好、讨厌的更气 |
| 按住不动 / 往上扯 / 往外拽 | `tease`：按住额头 0.3 秒 = 蓄力弹脑门；从头顶按住往上拽 = 抢头冠(有 `notiara.png` 才有)；按住杖头往外(离开她身子那边)拽 = 抢法杖(有 `wand.png` 就有)。往别的方向拖还是照常把她拎起来 |
| 滚轮 | 停下散步；插件先问(究极生气时不让转)；睡着 → 转醒生气；被拖/在飞时不转；闹别扭 → 扭头 |
| 隐藏 / 睡着 / 被丢 / 转圈 | 结束吃后效果 |

究极生气(`water` 插件，强行浇水后 45 秒)时：摸头被拍开，连摸 5 次才哄好；滚轮不让转；戳她第 1 下瞪你、第 2 下扭头不理、3–4 下警告、第 5 下起跺脚朝你吹风(4 秒一次)。每戳一下多气 4 秒(剩余最多回到 45 秒)；摸到一半又戳 = 前功尽弃，摸头次数清零。

## 7. 行为变化记录

### 2026-10-28 接口重构

条件判断改成查表后，用 2 万组随机状态和旧写法逐条比对过，结果一致，只有下面这些有意的变化：

- 去追蝴蝶：现在"晕的计时还没到"也不追(以前只看表情是不是 dizzy)。
- 插件现在可以通过 `busy()` 报活动。`vomit` 和 `water` 报了之后，转吐、浇水、强行浇水和 45 秒究极生气期间，蝴蝶不会自己飞来，她也不去追，空闲小动作、随机冒话和偷吃都暂停，DLC 的 `say` 回 `busy`。以前究极生气时蝴蝶照样会来，她还会去追。
- `live_say` 的转圈判断从 `spin_rem > 0.5` 改成 `> 0`(差别不到一帧)。
- 插件现在收得到 `state` `sleep` `wake` 事件(以前只在接了外部 DLC 时才发)。
- 新事件：`rps` `fortune` `focus_start` `focus_end` `reminder`。
- `stats.json` 里插件用 `inc()` 记的计数(比如 `vomits`)重启后不再清零。

### 2026-10-29
